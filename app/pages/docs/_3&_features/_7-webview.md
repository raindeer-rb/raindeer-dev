Because Raindeer uses an event loop and is fast, you can build a desktop app with web technologies. This is similar to Electron, you get to use HTML/CSS on the frontend back the back end is Raindeer instead of Node

## Template

Clone the [raintron]() template repository to begin your desktop application.

## Webview

The webview_ruby gems enables the native OS webview into your web application.

## Tebako

The tebako gem packages your web app up into a distributable app; Ruby interpreter, gems, native extensions and an executable per OS.
